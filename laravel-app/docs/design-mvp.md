## 📘 スキルログ管理システム 設計書（MVP版）

### 🎯 概要

学習したいスキルを一覧として登録し、それぞれの日々の進捗を管理するシステム。
「スキル一覧」から対象をクリックすることで、関連する進捗ログを確認・追加できる。

### 🗂 データモデル

#### スキル (`skills`)

| カラム名 | 型 | 説明 |
|---|---|---|
| id | bigint PK | 主キー |
| title | string | スキル名（例：Laravel, React） |
| description | text | スキル概要 |
| created_at | timestamp | 登録日時 |
| updated_at | timestamp | 更新日時 |

#### スキル進捗 (`skill_progresses`)

| カラム名 | 型 | 説明 |
|---|---|---|
| id | bigint PK | 主キー |
| skill_id | bigint FK | 関連スキルID（skills.id） |
| progress_date | date | 学習日付 |
| content | text | その日の進捗内容（例：教材2章完了など） |
| created_at | timestamp | 登録日時 |
| updated_at | timestamp | 更新日時 |

### 🖥 画面設計

1. スキル一覧画面
   - スキルのタイトルと概要を一覧表示
   - 「新規スキル登録」ボタン
   - 各スキルの「詳細を見る」リンク

2. スキル登録画面
   - 入力項目：
     - タイトル（必須）
     - 概要（任意）
   - 保存ボタン

3. スキル詳細画面（進捗表示・追加）
   - 表示内容：
     - スキルタイトル
     - スキル概要
     - 「進捗ログ一覧」テーブル（全件表示）
       - 日付
       - 進捗内容
     - 「進捗追加」ボタン

4. スキル進捗登録画面
   - 入力項目：
     - 日付（デフォルト=今日）
     - 進捗内容（テキスト）
   - 保存後、スキル詳細画面に戻る

### ✅ 機能要件まとめ

- スキル一覧を登録・編集・削除できる
- スキルをクリックすると詳細が見られる
- 詳細画面で日々の進捗を全件表示
- 進捗ログを追加できる
